실습 1
1. 각자 자기 이름으로 브랜치 만들기 (예: nkw26-task, kim-task)

2. 각자 파일 하나씩 만들어서 push 하기

3. 각자 Pull Request 올리기

4. 서로 PR 들어가서 "잘 하셨네요!" 댓글 달아주고 Merge 버튼 눌러주기

5. 마지막으로 모두가 git checkout main 하고 git pull 받기
